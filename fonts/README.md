# Polices embarquées

Fichiers `woff2` (sous-ensembles `latin` et `latin-ext`) téléchargés depuis Google Fonts et servis localement via `../sf-fonts.css`, pour que l'app fonctionne hors ligne dès le premier lancement et n'envoie aucune requête à Google.

| Famille | Auteurs / source | Licence |
|---------|------------------|---------|
| Cinzel | Natanael Gama — github.com/NDISCOVER/Cinzel | SIL OFL 1.1 |
| Cormorant Garamond | Christian Thalmann — github.com/CatharsisFonts/Cormorant | SIL OFL 1.1 |
| DM Mono | Colophon Foundry — github.com/googlefonts/dm-mono | SIL OFL 1.1 |
| Lato | Łukasz Dziedzic — latofonts.com | SIL OFL 1.1 |
| Syne | Bonjour Monde — github.com/bonjour-monde/Syne | SIL OFL 1.1 |

Pour mettre à jour : régénérer `sf-fonts.css` depuis l'API `fonts.googleapis.com/css2` et retélécharger les fichiers.
